# 📖 Mein Blog – React + Tailwind Projekt

Dies ist ein persönliches Blog-Projekt, erstellt mit **React** und **Tailwind CSS**. Die Website ist als moderne, responsive Blogplattform gedacht, auf der Beiträge veröffentlicht, gelesen und eventuell kommentiert werden können.

---

## 🚀 Features

- ⚛️ Reaktionsschnelle UI mit React
- 🎨 Styling mit Tailwind CSS
- 📝 Struktur für Blogposts vorbereitet
- 🔍 SEO-freundliche Struktur
- 🌙 Dark-Mode (optional)

---

## 🛠️ Installation

1. **Repository klonen**
   ```bash
   git clone https://github.com///
   cd /

2. **Anhängikeiten installieren**
   ```bash
   npm install

3. **Entwicklungsserver Starten**
   ```bash
   npm run dev

4. **Projekt im Browser öffnen**
   
   Gehe zu: http://localhost:3000
